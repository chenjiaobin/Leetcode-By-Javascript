# 概念

## 时间复杂度

时间复杂度用来衡量算法运行时间随着输入规模的增长而增长的趋势，简单来说，它表示算法运行的快慢程度和数据量大小的关联。

## 空间复杂度

空间复杂度是衡量算法运行过程中额外占用的内存空间。

## 内排序

内排序是指排序过程中数据元素全部放在内存中进行的排序。这些算法不需要频繁的访问外部存储设备，因此速度较快。

## 外排序

外排序是指待排序的数据量很大，内存无法一次性容纳全部数据，需要借助外部存储设备来负责排序。一般分为两个步骤：分块排序和合并排序。分块排序将数据分成若干个可以放入内存的小部分，对每个小部分进行排序；合并排序将排序好的小部分合并成一个有序的大文件。合并的过程可能需要频繁的在内存和外部存储设备之间交换数据。

## 稳定性

稳定性在排序算法中也是比较重要的，如果是稳定的话，那么相同元素的相对位置不会发生改变。比如，数组[1,1,2]，排序数组的第一个1和没排序前数组的第一个1是同一个，下标是0，排序后还是0。
